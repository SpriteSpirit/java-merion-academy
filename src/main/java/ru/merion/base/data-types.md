## Типы данных

**Типы данных** – это категории, которые определяют:

- вид и свойства данных, хранящихся в переменных;
- как компилятор/интерпретатор будет их обрабатывать;
- допустимые операции;
- объём памяти для хранения.

### Примитивные типы (хранят значение напрямую)

- **Целые числа:** `byte`, `short`, `int`, `long`
- **Дробные числа:** `float`, `double`
- **Символы:** `char`
- **Логические:** `boolean`

### Ссылочные типы (хранят адрес объекта)

- `String`, массивы, классы, интерфейсы

### Примеры для ссылочных типов

```java
String name = "Java"; // строки  
int[] numbers = {1, 2, 3}; // массивы  
Scanner scanner = new Scanner(System.in); // объекты классов  
```

### Особенности:

- примитивы работают быстрее, но ограничены в функциональности.
- ссылочные типы могут быть `null`, поддерживают методы (например, `String.length()`).

В `Java` есть примитивные типы (например, `int`) и их обёртки (например, `Integer`). Разберём
различия и случаи использования.

### Примитивные типы vs Обёртки (`Wrapper Classes`)

1. Примитивные типы (например, int, boolean)
    * Хранят значение напрямую (не являются объектами).
    * Быстрые и экономят память (работают в стеке).
    * Не могут быть null (имеют значения по умолчанию: 0, false и т.д.).
    * Не имеют методов (только значение).
    * Создаются присваиванием значения
    * Имеют строго заданный диапазон допустимых значений 
    * В аргументы методов попадают копии значения переменной (это передача по значению)

    
   ```java
   import java.util.ArrayList;
   import java.util.List;
   
   Integer age = 25;                           // авто-упаковка (int -> Integer)
   String text = "123";
   int num = Integer.parseInt(text);           // метод обёртки
   
   List<Integer> numbers = new ArrayList<>();  // только обёртки!
   numbers.add(42);
   ```

2. Автоупаковка (Autoboxing) и Распаковка (Unboxing)
   * Java автоматически преобразует примитивы ↔ обёртки:
   
   ```java
   // Автоупаковка: int -> Integer
   Integer boxed = 100;  

   // Распаковка: Integer -> int
   int unboxed = boxed;  
   ```
   ⚠️ Важно!
   * `==` для обёрток может давать false (лучше используйте equals()):
   
   ```java
   Integer a = 200;
   Integer b = 200;
   System.out.println(a == b);  // false! (для значений вне диапазона -128..127)
   ```
3. Когда что использовать?
   * Примитивы – для вычислений, циклов, когда null не нужен.
   * Обёртки – для коллекций, API, работы с null и методами.

4. Список всех примитивов и обёрток

|Примитив|Обёртка|
|-----------|--------|
|byte|Byte|
|short|Short|
|int|Integer|
|long|Long|
|float|Float|
|double|Double|
|char|Character|
|boolean|Boolean|

### Пример:
```java
// Примитив (лучше для производительности)
int result = 10 * 5;  

// Обёртка (нужна для коллекции)
List<Integer> numbers = Arrays.asList(1, 2, 3);  

// Парсинг строки в число (метод обёртки)
int parsed = Integer.parseInt("456");  
```

### Массивы
- хранят упорядоченные однотипные коллекции элементов. 
- элементы доступны по индексу.

### Структуры и классы
- это способы объединения нескольких переменных разного типа в один объект
- это позволяет создавать более сложные и организованные данные, которые можно использовать в программе. 
- в Java аналогами структур являются классы без методов или с минимальной логикой.

### Перечисления (Enum)
- специальный набор данных, который позволяет создавать набор именованных констант.
- они упрощают работу с фиксированными наборами значений
- делают код более читаемым и предотвращают ошибки
- Это аналогично enum в C и C++
- но в Java enum — это полноценный класс, который может содержать поля, методы и конструкторы.

```java
public enum Day {
 MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}
// Использование enum:
Day today = Day.MONDAY;

if (today == Day.MONDAY) {
 System.out.println("Сегодня понедельник");
}
```
### Интерфейсы
- определяют контракт, который должны выполнять классы, реализующие этот интерфейс
- содержат только абстрактные методы и константы
- позволяют достичь абстракции и полиморфизма

### Списки (List)
- динамически расширяемые коллекции объектов
- существует несколько реализаций списков: ArrayList, LinkedList
- ArrayList, LinkedList предоставляют разные способы хранения и доступа к данным

### Множества (Set)
- коллекции уникальных элементов
- реализации `HashSet` и `TreeSet` обеспечивают быстрый доступ и автоматическое управление дубликатами

### Словари (Maps)
- ассоциативные массивы или хеш-таблицы
- реализуют систему хранения: коллекция пар `ключ-значение`
- распространены реализации словарей `HashMap` и `TreeMap`

### Значения переменных по умолчанию
- каждый тип данных (примитивный и ссылочный) имеет значение по умолчанию
- значение по умолчанию будет присвоено переменной, если ее не инициализировали явно

#### Примитивные типы данных:
   ```java
   byte: 0
   short: 0
   int: 0
   long: 0L
   float: 0.0f
   double: 0.0d
   char: '\u0000' //(символ NUL)
   boolean: false
   ```
#### Ссылочные типы данных:
 - для ссылочных типов данных (таких, как классы и интерфейсы) значение по умолчанию — `null`.

### Boxing (упаковка) и unboxing (распаковка) 
- это механизмы для автоматического преобразования между примитивными типами и их классами-обёртками.

### Зачем они нужны?
1. Использование примитивов там, где требуются объекты
   > Java — частично объектно-ориентированный язык. 
   > Некоторые структуры данных (например, коллекции List, Map) и API работают только с объектами, 
   > но не с примитивами.

   ```java
   int number = 10;
   List<Integer> list = new ArrayList<>();
   list.add(number); // Автоупаковка (auto-boxing): int → Integer
   
   int unboxedNumber = list.get(0); // Автораспаковка (auto-unboxing): Integer → int
   ```

2. Работа с null и отсутствующими значениями
   > Примитивы не могут быть null, но их обёртки — могут. 
   > Это полезно, например, в БД, JSON или API, где значение может отсутствовать.

   ```java
   Integer age = getUserAgeFromDatabase(); // Может вернуть null
   if (age != null) {
       System.out.println(age + 10); // Автораспаковка
   }
   ```
   
3.  Использование методов классов-обёрток
   > У обёрток есть полезные методы, которых нет у примитивов:
   
   ```java
   int num = Integer.parseInt("123"); // Статический метод Integer
   boolean isLetter = Character.isLetter('A'); // Метод Character
   ```
**⚠️ Осторожно: подводные камни!**

1. **Производительность**
   * Каждый раз при автоупаковке создаётся новый объект. В циклах это может снижать скорость:
   ```java
   for (Integer i = 0; i < 100_000; i++) { 
       // Создаётся 100 тыс. объектов Integer!
   }
   ```
   
2. **NPE (NullPointerException) при распаковке:**
   * Если обертка `null`, а код пытается ее распаковать - удет ошибка:
      
   ```java
   Integer value = null;
   int num = value; // NPE!
   ```
3. **Сравнение через `==`**
   ```java
   Integer a = 100;
   Integer b = 100;
   System.out.println(a == b); // true (значения кэшируются для -128..127)
   
   Integer c = 200;
   Integer d = 200;
   System.out.println(c == d); // false! Нужно equals()!
   ```
   
### **Вывод: когда использовать?**
> Boxing/unboxing полезен для:
   * Коллекций (List<Integer>).
   * Работы с null.
   * Использования методов обёрток (Integer.parseInt()).

> Лучше избегать в:
   * Высокопроизводительных вычислениях.
   * Частых операциях в циклах.

### **Пример:**
```java
// Чтение чисел из строки (используются методы Integer)
String input = "10, 20, 30";
String[] parts = input.split(", ");
List<Integer> numbers = new ArrayList<>();

for (String part : parts) {
    numbers.add(Integer.parseInt(part)); // Автоупаковка int → Integer
}

int sum = numbers.stream()
                 .mapToInt(Integer::intValue) // Явная распаковка
                 .sum(); // Примитивы для скорости
```
