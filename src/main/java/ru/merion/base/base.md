## Какие существуют базовые типы переменных в Java?

- **byte** - для целочисленных чисел в диапазоне: от -128 до 127. занимает 1 байт
- **short** - для целочисленных чисел в диапазоне: от -32768 до 32767. занимает 2 байта
- **int** - для целочисленных чисел в диапазоне: от - 2147483648 до 2147483647. занимает 4 байта
- **long** - для целочисленных чисел в диапазоне: от –9 223 372 036 854 775 808 до 9 223 372 036 854 775 807. занимает 8 байт
- **float** - для вещественных чисел. занимает 4 байта
- **double** - для вещественных чисел. занимает 8 байт
- **char** - для одиночного символа в кодировке UTF-16. занимает 2 байта. (также можно записывать целые числа в диапазоне от 0 до 65535)
- **boolean** - для булевых значений true и false (размер спецификацией языка строго не определен)

**Такое количество типов нужно для того, чтобы:**
- Программа должна расходовать как можно меньше памяти
- Программа должна работать как можно быстрее и быть надежной

## Процедурное программирование
 - способ написания программ, где весь код разбивается на небольшие части: процедуры или функции.
 - эти части кода представляют собой набор инструкций, которые выполняют определенную задачу.
 - процедурное программирование помогает сделать код более структурированным, понятным и удобным для сопровождения, т.к.
 - каждая процедура отвечает только за одну конкретную задачу

## ООП
- подход к написанию программ, при котором основное внимание уделяется созданию объектов
- эти объекты представляют собой реальные или абстрактные сущности.
- каждый объект - это самостоятельная единица, которая содержит данные (свойства), методы (функции).
- основные принципы ООП:
  - инкапсуляция (скрытие деталей реализации)
  - наследование (создание новых классов на основе существующих)
  - полиморфизм (использование единых интерфейсов для разных типов объектов)
  - абстракция
- такой подход помогает структурировать код, делает его более понятным и удобным для поддержки и расширения.

### Класс
- чертеж, описывающий объект, его свойства и методы для работы с ним.
- объект - это конкретная сущность, созданная на основе класса
- объект обладает состояние, поведением и индивидуальностью. (с) Гради Буч

### Наследование
- позволяет описать новый класс на основе существующего класса или польностью заимствованной функциональностью.
- позволяет создавать иерархии классов
- позволяет переиспользовать уже написанный код, избегая его дублирования
- реализуется с помощью extends
- при наследовании класс-наследник получает доступ ко всем не приватным полям и методам родительского класса.
- при наследовании перенимается и состояние и поведение класса-родителя.
- дочерний класс полностью реализует все методы и свойства родительского класса и ведет себя так, как ожидается по контракту.
- производный класс может расширять возможности родительского класса, добавляя новые методы или переопределяя существующие для изменения поведения
- позволяет создавать более гибкую и расширяемую иерархию
- в Java отсутствует множественное наследование

### Инкапсуляция
- позволяет управлять доступом к данным внутри объекта
- поля класса приватные, а доступ к ним происходит через публичные методы (геттеры и сеттеры)

#### Модификаторы доступа
- public: доступ из любого места.
- protected: доступ внутри текущего класса, его подклассов и в том же пакете.
- private: доступ только внутри текущего класса.
- default: доступ только в том же пакете.

#### Геттеры/Сеттеры
- геттеры: методы, которые предоставляют доступ к значениям приватных полей. Получение поля извне.
- сеттеры: методы, которые позволяют менять значения приватных полей. 
- сеттеры контролируют, какие значения могут быть установлены для поля.

### Полиморфизм
- позволяет объектам одного класса использовать методы другого класса, имея при этом различное поведение в зависимости от контекста.
- разные классы могут иметь общий интерфейс, но реализовывать эти методы по-разному.
- самый распространенный вид полиморфизма - полиморфизм подтипов (динамический полиморфизм)
- динамический полиморфизм достигается путем наследования и переопределения методов.
- полиморфизм - это возможность системы использовать объекты с одинаковым интерфейсом без информации о типе и внутренней структуре объекта.

### Абстракция
- позволяет разделять понятия "что делает объект" и "как это делает"
- предоставляет только необходимый интерфейс для взаимодействия с ним, скрывая детали реализации объекта
- может быть реализована через абстрактные классы и интерфейсы
- абстрактный класс не может быть создан напрямую, а только унаследован другими классами
- может содержать абстрактные методы, которые объявляют интерфейс, но не предоставляют реализацию
- классы, наследующие абстрактный класс, должны предоставить реализацию для всех абстрактных методов.
- интерфейс - набор методов, которые класс должен реализовать, чтобы соответствовать этому интерфейсу
- интерфейсы определяют контракты, которые класс должен соблюдать, но не предоставляет никакой реализации
- классы могут реализовать несколько интерфейсов одновременно

#### Преимущества абстракции
- упрощение сложности: позволяет сконцентрироваться на важных аспектах объекта, игнорируя лишние детали.
- модульность: помогает разделить программный код на независимые модули, упрощая разработку и поддержку.
- сокрытие деталей реализации: пользователи объекта могут взаимодействовать с ним, не зная, как именно он работает внутри.
- улучшенная коммуникация: предоставляет четкий интерфейс для взаимодействия, упрощая коммуникацию между членами команды.
