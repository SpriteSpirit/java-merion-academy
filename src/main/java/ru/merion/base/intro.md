## Java Intro
**Java - мультипарадигменный язык программирования, строго типизированный и объектно-ориентированный язык программирования, который может использоваться для:**
- написания backend и REST API
- написания утилит и консольных приложений
- написания десктопных приложений
- написания мобильных приложений

>Язык Java был создан в 1995 году и широко используется в различных индустриях.
Java – это многоплатформенный, объектно-ориентированный и строго типизированный язык, 
который сам по себе может использоваться как платформа. 
Это быстрый, безопасный и надежный язык программирования для всего: от мобильных приложений и 
корпоративного ПО до приложений для работы с большими данными и серверных технологий.

### Многоплатформенность
Java разработан с учетом концепции "написать один раз, запускать где угодно". 
Это означает, что приложения, написанные на Java, могут быть скомпилированы в байт-код, 
который исполняется на Java Virtual Machine (JVM). Таким образом, Java-приложения могут работать на 
разных операционных системах без необходимости изменения кода, что делает их очень переносимыми.


### Богатая библиотека и экосистема
Java имеет обширную стандартную библиотеку и множество сторонних библиотек и фреймворков, 
что значительно упрощает разработку приложений. Экосистема Java также предоставляет инструменты 
для тестирования, сборки, управления зависимостями и другие ресурсы для эффективной разработки.

### Безопасность
Java имеет встроенные механизмы безопасности, такие как контроль доступа и управление памятью, 
которые помогают предотвратить ошибки, связанные с утечками памяти или несанкционированным доступом 
к данным.

### Использование в широком спектре областей
Java может применяться в веб-разработке, мобильной разработке (Android), 
корпоративном программировании, научных и инженерных вычислениях, 
игровой индустрии и других областях, что делает его универсальным инструментом.

### Стабильность и надежность
Java обладает хорошо продуманными механизмами управления памятью, автоматической сборки мусора и 
исключениями, что способствует стабильной и надежной работе приложений.

### Обратная совместимость
Java обратно совместима, что означает, что приложения, написанные на более старых версиях языка, 
в большинстве случаев могут быть запущены на новых версиях JVM без изменений.

### Как работает Java
- компилирует код в байт-код
- байт-код - промежуточный набор инструкций, который не зависит от конкретной платформы или архитектуры.
- компиляция выполняется с помощью компилятора Java (javac), который преобразует исходный код в байт-код.
- JVM интерпретирует и выполняет байт-код или может использовать JIT (Just-In-Time) компиляцию 
 для преобразования байт-кода в машинный код на исполняемой платформе.
-  JVM является платформой, на которой выполняется байт-код, и поскольку каждая операционная система 
имеет свою реализацию JVM, Java-приложения могут работать на различных операционных системах без изменения исходного кода.

>JVM (Java Virtual Machine) интерпретирует байт-код, то есть выполняет его, переводя инструкции в машинный код, понятный конкретной системе. Однако JVM также использует технологию Just-In-Time (JIT) компиляции, которая позволяет значительно повысить производительность. Когда JVM запускает программу, она сначала интерпретирует байт-код, выполняя его по мере необходимости. Но при этом JVM анализирует часто используемые участки кода и в процессе выполнения может их компилировать в нативный машинный код с помощью JIT-компилятора. Этот нативный код сохраняется в кэше и используется повторно, что ускоряет выполнение программы. Таким образом, JVM не только интерпретирует байт-код, но и использует JIT для динамической компиляции наиболее "горячих" участков кода в машинный язык, что позволяет добиться высокой скорости выполнения приложений на Java.


**JVM - Java Virtual Machine**
- виртуальная машина, которая выполняет байт-код Java, Groovy, Kotlin, Java
- отвечает за управление памятью и оптимизацию кода

**JRE - Java Runtime Environment**
- предназначена для запуска приложений
- обеспечивает необходимую среду выполнения
- содержит jvm, библиотеки и другие файлы, необходимые для работы программы

**JDK - Java Development Kit**
- содержит инструменты для разработки и выполнения Java-предложений
- содержит JRE (JVM, библиотеки, другие файлы)
- содержит компилятор, отладчик, генератор документации, утилиты для анализа кода

**Преимущества Java**
- кроссплатформенность
- производительность
- многопоточность
- безопасность
- надежность

**Фреймворк Spring**
Это набор инструментов для разработки приложений.

**Сборщики проектов**

Этапы сборки:
1. Исходный код компилируется в байт-код
2. Подгружаются необходимые версии библиотек
3. Формируются исполняемые файлы, например, .jar или .war, документация

### Компиляторы. 
> Вся программа написана в естественном английском синтаксисе с помощью компилирующих программ, 
> а затем язык компилирует (или переводит) весь код в машинный код. После этого скомпилированный 
> код запускается на оборудовании.

### Интерпретаторы. 
> С помощью интерпретирующих программ каждое высокоуровневое выражение кода интерпретируется 
> в машинный код в режиме реального времени.  Зафиксированные предписания немедленно выполняются 
> аппаратным обеспечением перед просмотром следующего предписания.

### Среда времени выполнения Java
> Программа Java была первым языком, объединившим оба описанных выше метода с использованием JVM. 
> Компилятор кода Java называется виртуальной машиной Java. Любой файл Java сначала компилируется 
> в байт-код. Байт-код Java может работать только в JVM. Затем JVM интерпретирует байт-код для 
> запуска на базовой аппаратной платформе. Поэтому, если приложение работает на компьютере с Windows, 
> JVM интерпретирует его для Windows. Однако при работе на платформе с открытым исходным кодом,
> такой, как Linux, JVM интерпретирует его для Linux.

### Экосистема Java
Внутри экосистемы существует множество семейств технологий, внутри Java:
- Java Standard Edition (Java SE): 
  - содержит базовый набор библиотек, включенный в стандартную поставку Java.
  - включает основные классы и методы для работы с данными, потоками, сетями, графикой и другими общими задачами. 
  - Open Java Development Kit (OpenJDK) - бесплатная реализация Java SE с открытым исходным кодом.
- Java Enterprise Edition (Java EE, Jakarta EE):
  - ранее известный как J2EE, это расширение Java для создания корпоративных приложений
  - включает в себя спецификацию для работы с веб-серверами, сервлетами, EJB (Enterprise JavaBeans)
  - JMS (Java Message Service) и другими технологиями.
- Spring Framework:
  - популярный фреймворк для разработки Java-приложений
  - предоставляет множество модулей для веб-разработки, взаимодействия с БД, управления транзакциями, 
  - безопасности и других аспектов.
- JavaFX:
  - платформа лдля создания графических пользовательских интерфейсов (GUI)
  - используется для разработки настольных приложений, в том числе мультимедийных и интерактивных.
- Android Development:
  - Android - платформа для мобильной разработки, основанная на Java
  - рабработка мобильных приложений на Android выполняется с использованием Java и Android SDK
- Apache Maven и Gradle:
  - инструменты для управления зависимостями, сборки проектов и автоматизации процесса разработки
