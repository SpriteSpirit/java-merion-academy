## Пакеты в Java
Пакет — это механизм организации и структурирования кода, который:
1. **Группирует связанные элементы**
   > Объединяет классы, интерфейсы, подпакеты и другие компоненты в логические модули.
    ```java
    package com.company.ui.widgets; // Пакет для классов виджетов интерфейса
    ```
   
2. **Решает проблему конфликтов имён**  
    > Предоставляет уникальное пространство имён (namespace), 
    > позволяя использовать одинаковые имена классов в разных пакетах.
    ```java
    java.util.List  // Класс List в пакете java.util
    java.awt.List   // Другой класс List в пакете java.awt
    ```

3. **Упрощает поддержку и управление кодом.**
    > Позволяет разбивать большие проекты на модули.
    > Ограничивает видимость компонентов через модификаторы доступа (protected, package-private).

4. **Связь с файловой системой.**
   > Каждый пакет соответствует папке в файловой системе, что упрощает навигацию.
   
    **Структура:**
   ```markdown
    src/
      └── com/
          └── company/
              ├── utils/  // Подпакет
              │   └── StringHelper.java
              └── Main.java
    ```
5. **Стандартные соглашения.**

    * Имена пакетов пишутся в нижнем регистре (например, org.example.project).
    * Обычно используют обратный DNS (например, com.google.gson).

### Основные цели использования пакетов
- организация кода:
  - пакеты позволяют разделить код на логические группы, отражающие функциональность, предметную область или модуль. 
  - это улучшает читаемость и облегчает поиск нужных классов.
- управление именами:
  - пакеты предоставляют пространство имен, что позволяет избегать конфликтов имен между классами, 
  - если пакеты имеют одинаковые названия, то полное имя класса включает имя пакета.
- модульность и уровни доступа:
  - пакеты позволяют управлять доступом к классам и их членам с помощью модификаторов доступа (public, protected, private, default). 
  - классы внутри пакета имеют доступ к пакет-приватным (package-private) элементам друг друга.
- импорт и экспорт:
  - классы из одного пакета могут использовать классы из других пакетов. 
  - это достигается с помощью инструкций `import` и управляется модификаторами доступа.
- упрощение сборки и дистрибуции:
  - пакеты позволяют логически упорядочить классы в иерархии папок на диске, что упрощает сборку, дистрибуцию и обновление программ.

### Примеры импорта
1. Импорт класса:
    ```java
    import java.util.ArrayList;
    
    public class Main {
           public static void main(String[] args) {
               ArrayList<String> myList = new ArrayList<>();
               // ...
           }
       }
    ```
2. Импорт всех классов из пакета:
    ```java
    import java.util.*;
    
    public class Main {
        public static void main(String[] args) {
               List<String> myList = new ArrayList<>();
               // ...
           }
       }
    ```
3. Статический импорт:
    ```java
    import static java.lang.Math.PI;
    
       public class Main {
           public static void main(String[] args) {
               double radius = 5.0;
               double area = PI * radius * radius;
               // ...
           }
       }
    ```
