## Композиция (Composition)

### Идея:

- Один объект полностью составляет другой объект.
- Сильная связь: если родитель уничтожается, то и дочерние объекты тоже уничтожаются.
- Часто называют «has-a» relationship с полной ответственностью.

### Что значит «has-a relationship с полной ответственностью»

- «has-a» relationship — это когда один объект содержит другой объект как часть себя.
    - Пример: Car имеет Engine → Car содержит двигатель.
- «с полной ответственностью» (full responsibility) означает:
    - Родительский объект создаёт и управляет дочерним объектом.
    - Жизненный цикл дочернего объекта полностью зависит от родителя: если родитель уничтожается, то
      и дочерний объект тоже.

#### Иными словами:

`Композиция` = «объект полностью владеет своей частью».

```java
class Engine {

    void start() {
        System.out.println("Engine started");
    }
}

class Car {

    private Engine engine; // Car состоит из Engine

    Car() {
        engine = new Engine(); // Car создаёт двигатель
    }

    void start() {
        engine.start(); // делегируем метод
        System.out.println("Car started");
    }
}

public class Main {

    public static void main(String[] args) {
        Car car = new Car();
        car.start();
        // Когда car будет уничтожен, engine тоже перестанет существовать
    }
}
```

### Ключевые признаки композиции:

- Сильная связь между объектами.
- Родитель создаёт и управляет временем жизни дочернего объекта.
- Обычно `private` поле внутри класса.

## Агрегация (Aggregation)

### Идея:

- Один объект включает в себя другой объект, но не владеет им полностью.
- Слабая связь: уничтожение родителя не уничтожает дочерний объект.
- Используется, когда один объект может существовать независимо от другого.

```java
class Teacher {

    String name;

    Teacher(String name) {
        this.name = name;
    }
}

class School {

    private List<Teacher> teachers;

    School(List<Teacher> teachers) {
        this.teachers = teachers; // School агрегирует учителей
    }
}

public class Main {

    public static void main(String[] args) {
        Teacher t1 = new Teacher("Alice");
        Teacher t2 = new Teacher("Bob");

        List<Teacher> teacherList = new ArrayList<>();
        teacherList.add(t1);
        teacherList.add(t2);

        School school = new School(teacherList);
        // Даже если school уничтожится, учителя t1 и t2 остаются
    }
}
```

### Ключевые признаки агрегации:

- Слабая связь между объектами.
- Родитель не создаёт дочерний объект, получает его извне.
- Дочерний объект может существовать отдельно.

### Сравнение

| Характеристика   | Композиция              | Агрегация                |
|------------------|-------------------------|--------------------------|
| Связь            | Сильная                 | Слабая                   |
| Владелец объекта | Родитель создает объект | Родитель получает объект |
| Жизненный цикл   | Совпадает с родителем   | Независимый              |
| Пример           | Car → Engine            | School → Teacher         |

### Мнемоника:

- `Композиция` = часть целого, живёт и умирает вместе.
- `Агрегация` = использует объект, но не владеет им полностью.

# Композиция vs Агрегация в Java

## Композиция (Composition)

- Сильная связь, родитель создаёт дочерний объект
- Дочерний объект не существует без родителя

```text
Car
├─ Engine  ← Engine создаётся внутри Car
└─ Wheels
```

#### Пример кода:

```java
class Engine {

}

class Car {

    private Engine engine;

    Car() {
        engine = new Engine();
    } // Car создаёт Engine
}
```
