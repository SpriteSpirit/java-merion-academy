# Java Naming Conventions

| Элемент                      | Стиль именования            | Пример                             | Комментарий                                                                             |
|------------------------------|-----------------------------|------------------------------------|-----------------------------------------------------------------------------------------|
| **Пакет (package)**          | lower.case + точки          | `com.example.utils`                | Каждое слово маленькими буквами, разделяем точкой. Kebab-case и CamelCase не разрешены. |
| **Модуль (module)**          | lower.case                  | `com.example.myapp`                | Аналогично пакетам, используется с Java 9+.                                             |
| **Класс (class)**            | PascalCase / UpperCamelCase | `UserAccount`, `DataProcessor`     | Каждое слово с заглавной буквы.                                                         |
| **Интерфейс (interface)**    | PascalCase / UpperCamelCase | `Flyable`, `Serializable`          | Часто как классы; иногда с префиксом `I` (`IFlyable`).                                  |
| **Методы (method)**          | camelCase                   | `calculateSalary()`, `fetchData()` | Первая буква маленькая, каждое следующее слово с заглавной.                             |
| **Переменные (variable)**    | camelCase                   | `userAge`, `firstName`             | Как методы, но без скобок.                                                              |
| **Константы (static final)** | UPPER_CASE + подчёркивания  | `MAX_USERS`, `DEFAULT_NAME`        | Все буквы заглавные, слова через `_`.                                                   |
| **Локальные переменные**     | camelCase                   | `tempValue`, `counter`             | Как обычные переменные, используется внутри методов.                                    |
| **Параметры методов**        | camelCase                   | `int userAge`, `String firstName`  | Всегда маленькая первая буква.                                                          |

## Модуль в Java (Java 9+)
- Модуль — это единица агрегирования кода в Java, которая объединяет пакеты и управляет видимостью и зависимостями.
- Он позволяет контролировать, какие пакеты видны другим модулям, а какие остаются внутренними.
- Физически модуль не обязательно один файл: это может быть директория с .java или .class файлами, но главное — файл module-info.java.

### Структура модуля

```text
my-module/
├── src/
│   └── com.example.myapp/
│       ├── App.java
│       └── utils/
│           └── Helper.java
└── module-info.java
```

- module-info.java — обязательный файл, где объявляются:
    - имя модуля
    - зависимости на другие модули
    - экспортируемые пакеты

### Пример module-info.java:

``` java
module com.example.myapp {
    requires java.sql;          // зависимость от другого модуля
    exports com.example.myapp;  // пакет доступен другим модулям
}
```

### Отличия от Python

| Характеристика        | Java Module                               | Python Module               |
|-----------------------|-------------------------------------------|-----------------------------|
| Единица кода          | Модуль = набор пакетов + module-info.java | Модуль = один файл `.py`    |
| Управление видимостью | Да, через `exports`/`requires`            | Нет, всё видимо при импорте |
| Явное объявление      | Да, `module-info.java`                    | Нет, достаточно файла       |

### Ключевые моменты

- Модуль управляет зависимостями и видимостью пакетов.
- Один модуль может содержать много пакетов, каждый пакет — много классов.
- Python-модуль = 1 файл, Java-модуль = директория/множество пакетов + module-info.java.
- Модуль — это скорее логическая единица проекта, а не физический файл.
