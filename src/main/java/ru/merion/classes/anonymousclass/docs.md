Смысл **анонимных классов** в Java — это возможность быстро создать **класс “на месте”**, не давая ему имени, чаще всего для реализации интерфейса или наследования класса **только один раз**.

Пример:

```java
Swimmable swimmable = new Swimmable() {
    @Override
    public void swim() {
        System.out.println("Swimmable.swim()");
    }
};
```

Что здесь происходит:

1. `Swimmable` — это интерфейс.
2. Обычно, чтобы его использовать, нужно создать отдельный класс:

```java
class Fish implements Swimmable {
    @Override
    public void swim() {
        System.out.println("Swimmable.swim()");
    }
}
Swimmable swimmable = new Fish();
```

3. Анонимный класс позволяет **обойтись без отдельного файла/класса** и сразу создать объект, который реализует `Swimmable`.

**Плюсы анонимных классов:**

* Меньше кода, удобно для одноразовых реализаций.
* Можно создавать прямо там, где нужен объект (например, при передаче в метод).
* Позволяет использовать локальные переменные из внешнего метода (если они final или effectively final).

**Минусы:**

* Код может быть менее читаемым, если анонимный класс большой.
* Нет возможности переиспользовать этот класс в других местах (он “одноразовый”).

Пример с использованием метода:

```java
public void makeSwim(Swimmable s) {
    s.swim();
}

makeSwim(new Swimmable() {
    @Override
    public void swim() {
        System.out.println("Swim fast!");
    }
});
```

Здесь мы создаём объект на месте и сразу передаём его в метод, **без отдельного класса**.

💡 Коротко: анонимные классы — это быстрый способ реализовать интерфейс или расширить класс прямо в месте использования, без отдельного объявления.

```text
          +---------------------+
          |   AnonExample       |
          |  (класс с методом)  |
          +---------------------+
                     |
                     |  создаём объект
                     v
          +---------------------+
swimmable |  Анонимный класс   | <- этот класс нигде явно не объявлен
          +---------------------+
          | + swim()            |
          +---------------------+
                     |
                     |  вызов метода
                     v
            "Swimmable.swim()" выводится в консоль

```
💡 Пояснение:

- `swimmable` — переменная, которая хранит ссылку на объект.
- Класс этого объекта нет в коде с именем, он “одноразовый”.
- Когда `swimmable` больше не используется, объект может быть удалён сборщиком мусора.
